# 现状差距与优化实施方案

> 依据：项目源码审计（app shell / grid / admin / design system）＋ 参考产品功能梳理。
> 参考文档：`docs/product/参考产品功能梳理.md`
> 原则：先修数据正确性与高频操作，再改壳层与性能；所有新 UI 复用现有组件与 SCSS 变量，不新增同类样式。

## 1. 当前项目基线

- 技术栈：Django + DRF + Celery + PostgreSQL/pgvector + Redis；Nuxt 4 + Vue 3 + Vuex + SCSS。
- 部署：Docker Compose + 宝塔 Nginx + Caddy；对象存储 S3 兼容（Bitiful）。
- 已有能力：工作区、数据库/表格、Grid/Kanban/Calendar/Gallery/Form/Timeline 视图、过滤器（含过滤组）、排序、分组、仪表盘、自动化、Builder、文件/备份、管理员用户与邮箱验证、表格去重。
- 总体判断：底层能力不弱，主要短板集中在**高频交互一致性、错误处理、可发现性、无障碍、管理安全和首屏/重复加载性能**。

## 3. 本轮执行（Batch A：数据安全与批量操作）

### 已实施

1. 日期/时间单元格
   - 非法输入不再把 `copy` 置空；新增 `dateInvalid/timeInvalid`，单元格显示错误态。
   - 失焦时非法值不保存，保留旧值，避免静默清空。
2. 复制/粘贴隔离
   - `copySelection` / `pasteFromMultipleCellSelection` 在输入框、可编辑元素、已打开 Modal 下直接放行浏览器原生行为。
   - 网格快捷键在 Modal 打开时暂停。
   - 修复 `navigator.clipboard.writeText(Promise)`。
3. 批量删除
   - 复选框选择改用 ID 列表删除，跨滚动勾选不再漏删。
   - 删除前使用现有 `ConfirmModal` 二次确认，成功后 toast。
4. 批量选择栏
   - Grid 工具栏新增“已选择 N 行 / 删除 / 取消选择”，复用 `header__filter-*` 样式和 `ConfirmModal`。
5. 去重工具
   - 显示截断警告；超过预览上限时禁用手动保留模式；确认文案改为“至少 N 行”，避免低估删除范围。
6. 无障碍基线
   - 全局 `:focus-visible`；移除 viewport 禁止缩放。
   - Modal 增加 `role="dialog"` / `aria-modal`。
   - FormTextarea label 关联、FormInput `aria-invalid`、SwitchInput `role="switch"` + 键盘。
7. 性能
   - Caddy 对 `/_nuxt/*`、`/_i18n/*` 内容哈希资源设置一年 immutable 缓存。
8. 壳层小修
   - 管理侧栏随路由响应；通知去重；创建 work 区重复事件/错误处理修复。

### 回归范围

- Grid：单元格编辑、日期/时间、选择、复制粘贴、批量删除、去重、右键菜单、工具栏。
- 表单/设置：FormInput/FormTextarea/SwitchInput 的现有页面。
- 壳层：侧栏、通知、创建 work 区。
- 部署：Caddy 配置、静态资源缓存。

## 6. 样式与实现硬规则

1. 新样式只写独立 `.scss`，BEM；禁止 `<style scoped>`。
2. 只用 `$palette-*`；禁止 `$color-*`、`$white`、裸 hex。
3. 优先复用 `Button`、`FormGroup`、`FormInput`、`ConfirmModal`、`Context`、`CrudTable`、`SkeletonBlock`、`Alert`、`Badge`。
4. 可交互元素用 `<button type="button">` 或带 `href` 的 `<a>`；icon-only 必须有 `aria-label`。
5. 表单内非提交按钮显式 `button-type="button"`。
6. 新页面/弹窗验证 360 / 768 / 1024 宽度；不写固定宽度 ≥ 视口。
7. 新图片必须有 `loading="lazy"`、`width/height`、`decoding="async"`、`alt`；首屏图除外。
8. 不新增全局同步 CSS；模块样式跟随模块入口，重组件考虑异步加载。
9. 任何功能改动必须有对应回归路径；不能以“隐藏入口”代替根因修复。

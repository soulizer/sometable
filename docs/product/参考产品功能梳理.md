# 参考产品功能梳理

> 目的：为 sometable（Baserow 二次开发）的功能与体验优化提供外部参照。
> 参考对象：金数据、SeaTable、飞书多维表格、Airtable，并补充 Notion / Coda 等同类产品。
> 说明：只记录与本项目定位（工作数据管理、表格/表单/协作/自动化）相关的能力，不追求照搬所有商业功能。

## 1. 参考产品定位

| 产品 | 核心定位 | 对本项目最有价值的部分 |
| --- | --- | --- |
| 金数据 | 表单收集 + 数据管理 + 查询/收款/预约等业务闭环 | 表单字段规则、公开填写、数据查询、提交后行为、评论通知 |
| SeaTable | 表格界面的轻量关系数据库 | 视图、过滤/排序/分组组合、行详情、行/单元格着色、锁定视图、表单、统计、打印 |
| 飞书多维表格 | 数据库 + 多视图 + 自动化 + 仪表盘 + 应用模式 | 多视图切换、仪表盘、高级权限、自动化、移动端体验、AI 字段 |
| Airtable | 成熟的数据库/视图/协作产品 | 视图栏、字段配置、行高、颜色、批量操作、界面设计器、快捷键 |
| Notion / Coda | 文档 + 数据库 + 轻应用 | 行详情页、内联数据库、页面化展示、模板复用 |

## 2. 数据建模与字段

成熟产品的共同点：

1. **字段类型覆盖完整**
   - 文本、长文本、数字、货币、百分比、日期/时间、单选、多选、附件、人员、关联记录、查找、汇总、公式、自动编号、创建时间、创建人、最后修改时间、最后修改人、评分、进度、复选框、URL、邮箱、电话。
2. **字段配置清晰**
   - 字段名称、描述、必填、默认值、唯一约束、格式、精度、日期格式、时区、选项颜色、关联表/关联字段、是否允许空值。
3. **输入即校验**
   - 数字范围、文本长度、邮箱/URL/电话格式、日期范围、唯一性、正则/自定义规则。
   - 错误提示定位到具体单元格，而不是只给一条全局错误。
4. **默认值与自动填充**
   - 新建行时自动带入当前用户、当前时间、父记录关联值、上次选择值。
5. **字段级帮助**
   - 字段描述、示例值、填写提示；表单中可显示为帮助文本。
6. **字段变更安全性**
   - 改类型前提示影响范围；无法转换时给出预览/确认，不静默丢数据。

## 3. 视图与数据呈现

参考产品普遍支持：

- **Grid/表格视图**：高密度录入、批量选择、复制粘贴、行高切换、冻结列、列宽持久化。
- **Kanban/看板**：按单选/人员/关联字段分列，列内排序、快速拖拽改状态、卡片字段配置。
- **Calendar/日历**：按日期字段呈现，月/周/日切换，拖拽改期。
- **Gallery/画册**：以附件封面为主，适合图片/产品/资产。
- **Timeline/Gantt/时间线**：起止日期、依赖关系、缩放。
- **Form/表单**：公开填写、字段显隐逻辑、必填、说明、提交后跳转/提示、防重复提交。
- **Dashboard/仪表盘**：统计卡片、柱状/折线/饼图、筛选器联动、TopN。
- **List/列表、Tree/树形**（SeaTable 等）。

视图层共同能力：

1. 视图栏快速切换；每个视图独立保存过滤、排序、分组、隐藏列、行高、颜色。
2. 过滤支持 AND/OR 组合、过滤组、按当前用户/当前日期等动态条件。
3. 排序支持多字段、升降序。
4. 分组支持多级分组、折叠、分组统计。
5. 行/单元格着色：按单选字段或条件规则。
6. 视图锁定/保护：防止误改配置。
7. 视图分享：只读/可编辑、公开链接、嵌入。
8. 视图复制：复制过滤/排序/分组等设置。
9. 搜索：当前视图搜索、全表搜索、全局搜索（跨应用）。
10. 批量操作：选择行后批量删除、修改字段、导出、复制。

## 4. 表格交互与快捷键

高价值交互：

- 键盘导航：方向键移动单元格、Enter 进入/确认、Esc 取消、Tab 下一列、Shift+Tab 上一列。
- `Ctrl/Cmd + F` 当前视图搜索。
- `Ctrl/Cmd + A` 全选当前结果集/已加载行。
- `Delete/Backspace` 清空单元格或删除选中行（需明确语义）。
- `Ctrl/Cmd + C/V` 单元格/区域复制粘贴，支持从 Excel 粘贴。
- `Ctrl/Cmd + Z` / `Ctrl/Cmd + Shift + Z` 撤销/重做。
- `Ctrl/Cmd + K` 全局搜索/命令面板。
- 右键菜单：插入行、复制行、删除行、插入列、隐藏列、冻结列。
- 行详情：侧边抽屉/弹窗查看全部字段、评论、历史。
- 选择反馈：选中行数、批量操作栏、全选当前页/全部结果。
- 空状态：明确下一步操作，而不是空白表格。
- 加载：骨架屏、分页/虚拟滚动、后台加载不阻塞输入。

## 5. 表单与数据收集（金数据重点）

金数据值得借鉴的能力：

1. **表单设计器**
   - 字段拖拽排序、分组/分页、字段说明、占位提示、默认值、必填。
   - 显示逻辑：按条件显示/隐藏字段或页面。
   - 校验规则：长度、范围、正则、唯一、文件类型/大小/数量。
2. **发布与收集**
   - 链接、二维码、嵌入网站、移动端填写。
   - 开始/结束时间、收集数量上限、IP/提交次数限制、访问密码。
   - 防重复提交、草稿保存。
3. **提交后行为**
   - 自定义结束页、跳转 URL、显示提交编号、发送通知。
4. **数据查询**
   - 对外查询页：按手机号/编号等条件查询自己的记录，只允许修改指定字段。
5. **数据管理**
   - 提交数据进入结构化列表，支持筛选、批量处理、导出、评论、跟进状态。
6. **通知与协作**
   - 新数据通知、字段变更通知、@成员、评论、附件。
7. **业务扩展**
   - 收款、预约、考试、测评等场景模板；本项目不必全部实现，但应保留扩展点。

## 6. 协作、权限与治理

成熟产品共同能力：

- 工作区/团队/成员/角色。
- 邀请成员、邀请链接、待接受邀请、移除成员。
- 角色：所有者、管理员、编辑者、评论者、只读。
- 行/列级权限（飞书高级权限）：按角色限制可见字段、可编辑行、可导出/复制/打印。
- 公开分享：密码、过期时间、只读/可编辑、隐藏品牌、允许导出。
- 评论、@提及、通知中心、未读计数。
- 操作历史/审计日志：谁在何时改了什么。
- 回收站与恢复。
- 数据导出/备份/恢复。
- 登录安全：邮箱验证、密码策略、两步验证、SSO。

## 7. 自动化与集成

- 触发条件：新行、行更新、定时、表单提交、Webhook。
- 动作：更新行、创建行、发送通知/邮件、调用 HTTP、运行脚本/AI。
- 条件分支、循环、延迟、失败重试、运行历史。
- 集成：Webhook、邮件、Slack/飞书/企业微信、OpenAPI、MCP。
- 运行日志可查看输入/输出与错误原因。

## 8. 数据分析

- 仪表盘组件：统计卡、柱状图、折线图、饼图/环图、表格、筛选器。
- 图表配置：数据源、分组、聚合、排序、TopN、颜色。
- 仪表盘筛选器联动多个图表。
- 导出图表/数据。
- 统计口径清晰，空数据/加载/错误状态完整。

## 9. 体验与性能基线

参考产品共同的体验基线：

1. **首屏快**：路由级代码分割、懒加载重型编辑器/图表、图片压缩、字体控制。
2. **操作反馈快**：乐观更新、骨架屏、按钮 loading、Toast、错误可恢复。
3. **不阻塞**：大表分页/虚拟滚动；导入、导出、去重、备份走异步任务并显示进度。
4. **一致**：相同功能复用同一套按钮、弹窗、表单、空状态、确认框、提示。
5. **可发现**：快捷键提示、空状态引导、帮助文本、命令面板。
6. **可访问**：键盘可达、焦点可见、表单 label、对比度、aria 属性。
7. **移动端可用**：侧栏收起、表格横向滚动、底部操作、触控目标足够大。
8. **国际化**：无硬编码文案；日期/数字/时区符合语言环境。

## 10. 本项目应优先借鉴的能力（初筛）

结合 sometable 现状，优先考虑：

| 优先级 | 能力 | 理由 |
| --- | --- | --- |
| P0 | 表格快捷键与批量操作体验 | 高频、直接影响效率；已有部分基础 |
| P0 | 导出/下载/错误提示可靠性 | 已出现真实故障，必须根因修复 |
| P0 | 中文化完整性、统一空状态/加载/错误状态 | 直接影响可用性 |
| P1 | 视图栏与过滤/排序/分组的一致性 | 现有能力多，但入口和反馈不统一 |
| P1 | 行详情、评论、历史的整合 | 协作场景核心 |
| P1 | 表单视图体验（说明、必填、提交后行为） | 金数据核心优势，现有 form view 可增强 |
| P1 | 全局搜索/命令面板 | 提升跨表/跨应用导航效率 |
| P2 | 仪表盘筛选器联动、图表体验 | 现有 dashboard 可增强 |
| P2 | 行/单元格着色、视图锁定/复制 | SeaTable/Airtable 常用 |
| P2 | 移动端与无障碍优化 | 现有页面可用但不精致 |
| P3 | 高级权限（行/列级） | 改动大，需单独评估 |
| P3 | 对外查询页、收款/预约等垂直场景 | 业务扩展，非当前工作数据管理核心 |

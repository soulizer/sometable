# 开发小结

> 每一轮开发完成后，在这里记录做了什么、验证结果、遗留问题。

## 第 0 轮：基础部署（2026-11-20）

### 目标
将 `soulizer/sometable`（Baserow develop 分支）部署到 `/www/apps/sometable`，
通过 `sometable.com` 对外提供服务，并接入对象存储。

### 完成内容

1. **源码与仓库**
   - 源码位于 `/www/apps/sometable`，分支 `develop`。
   - 生成本机 SSH deploy key：`~/.ssh/sometable_deploy`，SSH alias `github-sometable`。
   - `origin` 已切换为 `git@github-sometable:soulizer/sometable.git`，已具备推送权限。

2. **运行栈（Docker Compose）**
   - 服务：caddy、backend、web-frontend、celery、celery-beat、celery-export、
     db（pgvector/pg15）、redis。
   - 镜像使用 `develop-latest`：仓库的迁移数量比 `2.4.3` 发布镜像多 15 个，
     用发布镜像会因 schema 不匹配而报错（实测 `core_userprofile.user_type` 缺失）。
   - Caddy 仅在内网暴露，绑定 `127.0.0.1:8088`。

3. **反向代理与 TLS**
   - `宝塔 Nginx` 终止 TLS，反代到 `127.0.0.1:8088`。
   - 证书：Let's Encrypt，覆盖 `sometable.com`、`www.sometable.com`、
     `sometables.com`、`www.sometables.com`，webroot 方式自动续期。
   - 站点配置：`/www/server/panel/vhost/nginx/sometable.com.conf`。

4. **域名归一化**
   - 四个域名全部 301 到 `https://sometable.com`（HTTP 也跳 HTTPS）。
   - 已实测：`www.sometable.com` / `sometables.com` / `www.sometables.com` → `sometable.com`。

5. **对象存储（缤纷云 S4）**
   - 桶 `drive`，前缀 `sometable/`，path-style 寻址。
   - 该桶为私有桶，不支持匿名读；对象 ACL 设为 `public-read` 也无法匿名 GET。
     因此启用签名 URL（`AWS_QUERYSTRING_AUTH=true`，有效期 7 天）。
   - 实测：上传后文件落在 `drive/sometable/user_files/`，签名 URL 下载返回 200。
   - **注意**：该桶与 `360note` 等其它项目共享，务必保证 `AWS_LOCATION=sometable`
     生效，避免写入 `user_files/` 顶层污染其他项目数据。

6. **账号与注册策略**
   - 管理员账号：`admin@sometable.com`（超级管理员，密码另行提供）。
   - 实例设置：关闭公开注册（`allow_new_signups=false`），隐藏管理员注册页。
   - 实测：`/api/user/token-auth/` 登录成功、`/api/admin/users/` 返回 200。
